# AWS Learning Tracks

Two 30-day tracks. Do them in order.

| Track | For | What you do each day |
|-------|-----|----------------------|
| **[AWS Architecture](aws_architecture/README.md)** | Learning to read and draw AWS architectures | Draw one architecture, from a single VPC up to a multi-Region production platform |
| **[AWS Mastery](aws_mastery/README.md)** | Engineers with 4–5 years of experience | Go inside one group of services: how it works, its limits, how it fails, what it costs, how to debug it |

Each day is one page: `aws_architecture/day-XX/index.html`. Open it in a browser.
